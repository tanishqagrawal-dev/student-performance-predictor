# EduPredict AI – Student Performance Prediction System 🎓

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-App-FF4B4B)](https://streamlit.io/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-ML-orange)](https://scikit-learn.org/)

**EduPredict AI** is a modern Machine Learning internship project designed to help educators and students predict academic outcomes based on key performance indicators. It uses advanced regression and classification algorithms to provide real-time insights into student success.

---

## 🚀 Project Overview

This project was developed as a comprehensive demonstration of Machine Learning concepts, focusing on:
- **Data Preprocessing & EDA**
- **Linear Regression** (Predicting precise marks)
- **Logistic Regression** (Pass/Fail classification)
- **Interactive UI/UX** with Glassmorphism and Neon design principles.

## 🎯 Key Features

- **Real-time Prediction:** Adjust sliders to see instant results for estimated marks and pass/fail status.
- **AI Smart Insights:** Intelligent suggestions based on student data (e.g., "Increase study hours").
- **Modern Dashboard:** Visualizations including Scatter Plots, Correlation Heatmaps, and Histograms.
- **Glassmorphism UI:** A premium, dark-mode interface with floating particles and smooth animations.
- **Confidence Scoring:** Understand the model's certainty for every prediction.

## 🛠️ Tech Stack

- **Frontend:** Streamlit (Custom CSS/JS for Glassmorphism)
- **Machine Learning:** Scikit-learn (Linear Regression, Logistic Regression)
- **Data Handling:** Pandas, NumPy
- **Visualizations:** Plotly, Seaborn, Matplotlib

## 📂 Project Structure

```text
├── app.py                # Main Streamlit Application
├── requirements.txt      # Project Dependencies
├── sample_dataset.csv    # Synthetic Student Performance Data
├── generate_data.py      # Script to generate realistic dataset
└── README.md             # Project Documentation
```

## ⚙️ How to Run

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```
